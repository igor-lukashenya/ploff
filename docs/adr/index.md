# Architecture Decision Records

We record significant architectural decisions as **ADRs** (Architecture Decision Records).

## What is an ADR?

An ADR captures a decision along with its context, consequences, and alternatives considered.
This creates a historical record of *why* things are the way they are — invaluable for
onboarding and future discussions.

## Creating a New ADR

1. Copy the template:
   ```bash
   cp docs/adr/000-template.md docs/adr/NNN-short-title.md
   ```
2. Number it sequentially
3. Fill in all sections
4. Submit as part of your PR

See [000-template.md](000-template.md) for the full template.
