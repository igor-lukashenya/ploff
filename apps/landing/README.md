# Ploff Landing

> The landing page for **Ploff (Project Lift Off)** — a monorepo boilerplate and launchpad
> for new projects.

An Astro static marketing landing page generated from the `astro-landing` template,
with translation (i18n), SEO, and per-language GEO (`llms.txt`) built in.

## Tech Stack

- **Astro** (static output) + **TypeScript**
- **Tailwind CSS** v4
- `@astrojs/sitemap` for `sitemap-index.xml`/`sitemap-0.xml`

## Commands

Run from the repository root:

| Command | Description |
| --- | --- |
| `make dev APP=landing` | Dev server on http://localhost:4321 |
| `make run APP=landing TASK=test` | Unit tests (Vitest) |
| `make run APP=landing TASK=lint` | Lint (ESLint) |
| `make run APP=landing TASK=typecheck` | Type-check (`astro check`) |
| `make run APP=landing TASK=build` | Production build to `dist/` |
| `make up` | Run in Docker Compose (unprivileged nginx, port 3001) |

## Site Settings

Edit `src/lib/site.ts` for site identity:

- `name` — human-readable site name (also set `site_name` at generation time)
- `url` — public URL; override at build/deploy time with `SITE_URL` (see `.env.example`)
- `locales` — the languages served (code, BCP-47 `lang`, and label)
- `links.github` / `links.docs` — the CTA and header/footer link targets

## Structure

```
src/
├── lib/site.ts        # site metadata + locales + links
├── lib/seo.ts         # URL helpers (canonical, hreflang, llms paths)
├── i18n/              # per-locale dictionaries + useTranslations()
├── components/        # Seo, header, footer, hero, features, language switcher
├── layouts/           # base layout (document shell + <Seo/>)
└── pages/             # index.astro (en) and es/index.astro (es)
public/
├── llms.txt           # GEO map for the default locale
├── llms-full.txt      # GEO full copy for the default locale
└── es/llms*.txt       # GEO files for Spanish
```

## SEO and GEO

The `<Seo>` component renders the title, description, canonical URL, `hreflang` alternates,
Open Graph + Twitter cards, JSON-LD (`Organization`), a sitemap link, and the `llms.txt`
discovery links (`rel="alternate" type="text/markdown"` + `rel="describedby"`).
`@astrojs/sitemap` emits `sitemap-index.xml` (with hreflang alternates) and `robots.txt` is
generated by `src/pages/robots.txt.ts`.

## Adding a language

To add a supported language (e.g. `fr`), make **all four** of these edits:

1. Add `'fr'` to `i18n.locales` in `astro.config.mjs`.
2. Add `src/i18n/fr.ts` (copy `en.ts`, translate every string).
3. Add `src/pages/fr/index.astro` (copy `es/index.astro`).
4. Add `public/fr/llms.txt` **and** `public/fr/llms-full.txt` (translate from the `es` copies).

**GEO must cover every supported language** — an untranslated locale still needs its own
`llms.txt` + `llms-full.txt` so AI tools can index it.
